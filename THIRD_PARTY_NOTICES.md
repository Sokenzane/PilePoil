## Material Symbols

- **What**: the interface icons (picker, refresh, center, screen, language, pin, compact / full mode, check, info, error, drop-down arrow), embedded as path data in `src/PilePoil.cs`.
- **Source**: [Material Symbols](https://fonts.google.com/icons) by Google, Outlined style, weight 400, from the npm package [`@material-symbols/svg-400`](https://www.npmjs.com/package/@material-symbols/svg-400) version 0.48.0.
- **License**: [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0), which is compatible with the GPL-3.0.
- **Changes**: SVG paths converted to absolute move / line / cubic Bézier commands on a 24×24 grid with [`tools/make_icon_paths.py`](tools/make_icon_paths.py). The shapes are unchanged.

The app icon and logo (`assets/`) are original work, part of Pile Poil.
